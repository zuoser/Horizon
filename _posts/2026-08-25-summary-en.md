### [Firefox 157 enables JPEG XL by default on all platforms](https://groups.google.com/a/mozilla.org/g/dev-platform/c/3YMV4MS34KA?pli=1) ⭐️ 8.0/10

Mozilla is enabling JPEG XL by default in Firefox 157 across all platforms, a significant step for modern image format adoption. JPEG XL is positioned as a next-generation web image format, and default support means Firefox users will be able to view such images without changing browser settings. The move matters because it gives web developers a standards-based format option that works in Firefox out of the box, while broader adoption still depends on other browser engines. Community comments indicate Chromium also appears to be pursuing JPEG XL support, with both Firefox and Chromium using the Rust-based jxl-rs implementation.

hackernews · yboris · Aug 25, 17:55 · [Discussion](https://news.ycombinator.com/item?id=49437946)

**「Background」** JPEG XL is a modern image format standardized in 2022 as ISO/IEC 18181, designed to offer better compression and features than legacy JPEG. After earlier hesitation in Chromium, Google Research developed jxl-rs, a Rust-based JPEG XL decoder used in both Chrome/Chromium and Mozilla Firefox. Mozilla now plans to enable JPEG XL by default in Firefox 157 in late September, following Chrome&\#x27;s move to ship the format.

**「Impact」** Firefox users will be able to view JPEG XL images by default once Firefox 157 ships, giving web developers a predictable path to serve the format to Firefox users without relying on a preference flag. Broader web adoption still depends on Chrome and Safari decisions, so JPEG XL’s practical reach will vary by browser.

**「Community discussion」** Commenters note that Chromium appears to be doing the same and discuss implementation questions, including the Rust-based jxl-rs used by Firefox and Chromium versus Apple’s already-shipped libjxl C++ code. Practical concerns include upload fields that do not support JPEG XL, automatic conversion to JPEG/PNG, and whether the format will reach older Windows 7/8 users remaining on Firefox 115.
